# 草

NICHEXに使った時間だけを塗る。勉強と運動は対象外。

## フィールド

| フィールド | 型 | 意味 |
|---|---|---|
| `date` | 文字列 | `YYYY-MM-DD`（Asia/Tokyo） |
| `minutes` | 数 | NICHEXに使った分。1以上で色が付く |
| `work` | 文字列 | 何をしたか一言 |
| `coba` | 真偽 | 中之島に行ったか。色には使わない |
