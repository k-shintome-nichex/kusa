# 草

平日も週末も同じ動線（起床 → co-ba中之島 → 仕事 → 帰宅 → 勉強）を、GitHub の草と同じ形式で見る静的ページです。ビルド不要。`index.html` を開くか、GitHub Pages に置いて使います。

## 4つのフィールド

`data/days.json` の各日は次の4つだけです。**平日も土曜・日曜も同じ形式**です。週末を「休み」として別扱いしません。週末の co-ba中之島は終日の予定として `coba: true` を立てます。

| フィールド | 型 | 意味 |
|---|---|---|
| `date` | 文字列 | 日付 `YYYY-MM-DD`（Asia/Tokyo） |
| `coba` | 真偽 | 中之島の co-ba に行ったか。週末も同じ |
| `work` | 文字列 | 仕事の短いメモ。空文字なら仕事なし |
| `study` | 文字列 | 勉強の短いメモ。空文字なら勉強なし |

存在しない日 = 報告していない日です。配列に無い日は「記録なし」です。

## 日を足す

`data/days.json` の `days` 配列にオブジェクトを1つ足します。

```json
{
  "timezone": "Asia/Tokyo",
  "started": "2026-09-01",
  "days": [
    {
      "date": "2026-09-01",
      "coba": true,
      "work": "短時間",
      "study": ""
    }
  ]
}
```

土曜・日曜も同じ4フィールドで足します。例：

```json
{
  "date": "2026-09-05",
  "coba": true,
  "work": "",
  "study": "英語"
}
```

## 濃さ（0–3）

次の3つのうち、当たった個数がその日の濃さです。

1. `coba === true`
2. `work` が空でない
3. `study` が空でない

週末も同じ数え方です。

## 例を見る

トグル「例を見る」は `data/sample.json` を読みます。メモはすべて「例」で、本番データではありません。初期状態はオフ（本番の空データ）です。

`days.json` の `days` は空のままにしてください。実記録を捏造しないこと。

## 開き方

- GitHub Pages / ローカルサーバ: `data/days.json` がそのまま読まれます。
- `file://` で直接開いた場合、ブラウザが JSON の fetch を拒むことがあります。そのときは空データと「例を見る」の内蔵フォールバックが使われます。日を足したあとは次で確認してください。

```bash
python3 -m http.server
```

週の始まりは月曜。タイムゾーンは Asia/Tokyo。
