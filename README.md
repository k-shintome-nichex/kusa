## 毎朝の記録

画面右上の「毎朝の記録」から、睡眠時間・身体の疲れ・心の疲れの推移と最近の記録を確認できます。データは `data/mornings.json` の `mornings` 配列へ、起床日を基準に追加します。

```json
{
  "date": "2026-09-30",
  "lightsOut": "23:30",
  "wake": "06:30",
  "sleepMinutes": 420,
  "body": 2,
  "mental": 1
}
```

| フィールド | 型 | 意味 |
|---|---|---|
| `date` | 文字列 | 起床した日。`YYYY-MM-DD`（Asia/Tokyo） |
| `lightsOut` | 文字列 | 前夜の消灯時刻。`HH:MM` |
| `wake` | 文字列 | 起床時刻。`HH:MM` |
| `sleepMinutes` | 数 | 睡眠時間（分）。省略時は `lightsOut` と `wake` から日またぎを考慮して計算 |
| `body` | 整数 | 身体の疲れ。1（すっきり）〜5（とても疲れた） |
| `mental` | 整数 | 心の疲れ。1（すっきり）〜5（とても疲れた） |

このサイトは静的な GitHub Pages のため、ブラウザから JSON ファイルを更新しません。記録の追加・修正は GitHub で `data/mornings.json` を編集してコミットしてください。
