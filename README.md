# 草

平日も週末も同じ動線（起床 → co-ba中之島 → 仕事 → 帰宅 → 勉強）を、GitHub の草と同じ形式で見る静的ページです。ビルド不要。`index.html` を開くか、GitHub Pages に置いて使います。

## フィールド

`data/days.json` の各日は次のとおり。**平日も土曜・日曜も同じ形式**です。週末を「休み」として別扱いしません。週末の co-ba中之島は終日の予定として `coba: true` を立てます。

| フィールド | 型 | 意味 |
|---|---|---|
| `date` | 文字列 | 日付 `YYYY-MM-DD`（Asia/Tokyo） |
| `coba` | 真偽 | 中之島の co-ba に行ったか。週末も同じ |
| `work` | 文字列 | 仕事の短いメモ。空文字なら仕事なし |
| `study` | 文字列 | 勉強の短いメモ。空文字なら勉強なし |
| `move` | 文字列 | 運動の短いメモ。空文字または省略なら運動なし。草の濃さには数えない |

存在しない日 = 報告していない日です。配列に無い日は「記録なし」です。

## 日を足す

`data/days.json` の `days` 配列にオブジェクトを1つ足します。

```json
{
  "timezone": "Asia/Tokyo",
  "started": "2026-09-01",
  "days": [
    {
      "date": "2026-09-01",
      "coba": true,
      "work": "短時間",
      "study": "",
      "move": "ジム"
    }
  ]
}
```

## 濃さ（0–3）

次の3つのうち、当たった個数がその日の濃さです。`move` は数えません。

1. `coba === true`
2. `work` が空でない
3. `study` が空でない

週末も同じ数え方です。
